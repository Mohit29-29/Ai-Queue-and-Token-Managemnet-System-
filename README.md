# AIoT-Based Queue Management System

An AIoT-based queue management system designed to digitize token generation, queue tracking, and user verification using an ESP32-CAM.

## 🚀 Features

- Digital token generation
- Queue position and token status tracking
- Estimated waiting-time management
- ESP32-CAM based user scanning and verification
- Authorized user verification
- Responsive web interface
- AIoT-based queue management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- ESP32-CAM
- Arduino IDE
- AI/ML

## 📌 Project Overview

The system provides a digital alternative to traditional queue management. 
Users can generate tokens and track their queue status digitally, while 
the ESP32-CAM is used for scanning and user verification.

The integration of IoT-based camera verification with queue management 
helps improve automation, authentication, and overall queue efficiency.

## ⚙️ System Workflow

1. User accesses the queue management system.
2. A digital token is generated.
3. User can track token status and queue position.
4. ESP32-CAM scans the user for verification.
5. The system verifies authorized access.
6. Queue status and estimated waiting time are updated.
